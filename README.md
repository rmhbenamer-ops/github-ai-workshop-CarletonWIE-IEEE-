# IEEE Carleton WIE — Coding with AI Workshop

Welcome! This repository is the participant starter kit for our beginner-friendly, hands-on workshop.

## Workshop project

You will build a **Study Session Planner** with help from an AI coding assistant. You will practice writing prompts, generating code, understanding what the code does, testing it, and debugging mistakes.

## Tools

- **Python 3** to run your programs
- **VS Code** or another Python editor
- **An AI coding assistant**, such as ChatGPT or GitHub Copilot Chat
- **GitHub** to access the workshop files

The AI assistant is separate from this repository. You can use it in a browser or through an editor integration.

## Getting started

1. Download or clone this repository.
2. Open the folder in VS Code.
3. Make sure Python 3 is installed.
4. Open the activity files and follow the instructions in each one.
5. Open `workshop-prompts/AI_PROMPTS.md` to copy the prompts into your AI assistant.

Run a Python file from the terminal:

```bash
python path/to/file.py
```

If that does not work on your computer, try `python3` instead.

## Windows setup

If you are using Windows, follow [`00-setup/WINDOWS_VSCODE_SETUP.md`](00-setup/WINDOWS_VSCODE_SETUP.md) to download and install Visual Studio Code, install Python, and prepare your editor.

## Workshop activities

| Activity | Folder | What you will practise |
|---|---|---|
| 1. Meet your AI assistant | `01-introduction/` | Asking questions and understanding basic Python |
| 2. Build a Study Session Planner | `02-study-session-planner/` | Planning and generating a small program |
| 3. Debugging challenge | `03-debugging/` | Finding, explaining, and fixing a bug |
| Prompt guide | `workshop-prompts/` | Copy-and-paste prompts for each activity |

## A good AI-assisted coding workflow

1. **Plan:** Explain what you want to build.
2. **Prompt:** Give the AI clear requirements and context.
3. **Review:** Read the suggested code and ask questions.
4. **Run:** Test the program yourself.
5. **Improve:** Ask for help with one change at a time.

## Important reminders

- AI-generated code can be incorrect. Always run and test it.
- Ask the assistant to explain unfamiliar code.
- Do not paste passwords, personal information, or confidential information into an AI tool.
- Follow the facilitator's instructions about which AI tools you may use.
- Only use code you understand and can explain.

Have fun experimenting!
