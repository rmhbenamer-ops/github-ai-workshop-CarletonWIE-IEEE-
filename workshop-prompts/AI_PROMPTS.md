# AI Prompt Guide

Copy these prompts into your AI coding assistant during the workshop. Replace bracketed text when needed.

## Activity 1 — Meet your AI assistant

**Prompt 1: Learn the basics**

> I am a beginner learning Python. Act as my coding assistant. Explain what variables, functions, and print statements are. Use simple examples and beginner-friendly language.

**Prompt 2: Try a small program**

> Show me a small Python example that asks a user for their name and favourite subject, then prints a personalized welcome message. Explain each line of code.

## Activity 2 — Build the Study Session Planner

**Prompt 3: Plan before coding**

> I want to create a beginner-friendly Python Study Session Planner. It should ask for the user's name, the number of study sessions, and the length of each session in minutes. It should calculate the total study time and display a personalized summary. Before writing code, break the project into smaller steps and explain which Python concepts I will need.

**Prompt 4: Generate a first version**

> Help me implement the Study Session Planner in Python. Use input() to collect information, variables to store it, a function to calculate total study time, and print() to display a summary. Keep the code beginner-friendly and explain each section. Help me work through the starter file rather than adding unnecessary features.

**Prompt 5: Add hours and minutes**

> Help me modify my Study Session Planner so that it displays the total study time in both hours and minutes. Explain the changes and show me how to test them.

**Prompt 6: Improve the user experience**

> Suggest a few ways to make the messages in my Study Session Planner clearer and friendlier. Keep the same functionality. Explain each suggested change before making it.

## Activity 3 — Debugging challenge

**Prompt 7: Find the bug first**

> This Python program is supposed to calculate the average of a list of study-session lengths, but the result is incorrect. Here is my code: [paste the code]. Identify the bug and explain why it happens. Do not rewrite the entire program yet.

**Prompt 8: Fix and test**

> Now help me fix the bug. Explain what needs to change, show the corrected code, and suggest two test cases I can use to check the result.

**Prompt 9: Handle an empty list**

> What happens if the session_lengths list is empty? Explain the problem and help me add a check so the program does not attempt to divide by zero.

## Final reflection

**Prompt 10: Think of improvements**

> Review my Study Session Planner. Suggest three additional features that could make it more useful. For each feature, explain what it would do and which Python concepts I would need. Do not implement the features yet.

## Prompting tips

- Give the AI context: say that you are a beginner and name the language.
- Be specific about what the program should do.
- Ask for an explanation, not just code.
- Ask one question or request one change at a time.
- If the answer is confusing, ask the AI to explain it another way.
- Run the code and test it yourself. AI can make mistakes.
